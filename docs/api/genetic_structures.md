# genetic_structures Module

Core genetic architecture definitions for the simulation.

## Overview

The `natal.frontend.genetics.structures` subpackage defines the immutable genetic architecture of the simulation, including chromosomes, loci, species, and genome templates. Its public classes (`Species`, `Chromosome`, `Locus`, `RecombinationMap`) are re-exported from `natal.frontend.genetics`.
