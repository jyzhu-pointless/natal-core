# 一次繁殖如何计算

[上一章](model_journey.md)中，100 只 A|a 雌性与 100 只 A|a 雄性，在每雌性产卵数为 2 的设置下，产生了 200 个后代。这一结果不是用“种群数量乘增长率”得到的，而是经过交配对象选择、配对、产卵、遗传分配、性别分配和合子适应度计算。

本章逐步拆开这个过程。正文中的公式和表格用于解释数值，不是待复制执行的代码。主线限定为**普通分阶段离散世代模型**：确定性、常染色体、无额外标签转换。后面再说明随机路径、年龄结构与融合 Wright–Fisher 的区别。

## 先分清规则、当前数量和临时结果

繁殖函数 `reproduction()` 读取 age-1 成体，写入 age-0 后代。它本身不把后代变为成体，也不清除旧成体；后续 survival 和 aging 才完成这些工作。

本例压缩后的个体类型顺序为 AA、Aa、aa，即 Z=3；配子顺序为 A、a，即 G=2。正文省略名称中的分隔符和 default 标签，实际类型名称仍然是 A|A@default 等。

| 数据 | shape 或索引 | 生命周期 |
| --- | --- | --- |
| 个体数量 `ind` | `(sex, age, Z)`，本例 `(2, 2, 3)` | 会话持续持有，每阶段更新 |
| 减数分裂表 M | `(sex, Z, G)` | 构建或遗传重编译时产生 |
| 配子融合表 F | `(G, G, Z)` | 构建或遗传重编译时产生 |
| 后代张量 P | `(female Z, male Z, offspring Z)` | 从 M、F 派生，繁殖时重复使用 |
| 性选择 fitness S | `(female Z, male Z)` | 决定交配对象的相对权重 |
| 有效雄性向量 | `(Z,)` | 本次繁殖的临时结果 |
| 交配概率 Q、配对数 C | 均为 `(Z, Z)` | 本次繁殖的临时结果 |
| 后代及分性别缓冲 | 每个 `(Z,)` | 本次繁殖完成后写回 age-0 |

P 描述亲本组合的遗传结果，C 描述本次实际有多少这样的组合。相同物种在两次运行中可以使用同一个 P，却因为亲本数量不同得到不同 C 和后代数量。

## 遗传规则准备：从两个配子到一个后代

### M 描述一个亲本产生什么配子

无转换的孟德尔模型中，雌雄使用相同的下表：

| 亲本类型 | A 配子概率 | a 配子概率 |
| --- | --- | --- |
| AA | 1 | 0 |
| Aa | 1/2 | 1/2 |
| aa | 0 | 1 |

完整 M 仍保留性别轴，不能因本例两份内容相同就认为该轴无用。性别相关的遗传机制可以使雌雄映射不同。

M 的一行是概率，不是配子数量。Aa 亲本的 `(1/2, 1/2)` 并不意味着该亲本只产生一个配子，也不决定它产多少卵。

### F 描述两个配子的融合结果

F 的前两轴保留雌雄配子的来源，最后一轴列出后代类型：

| 雌性配子 | 雄性配子 | 后代 `(AA, Aa, aa)` |
| --- | --- | --- |
| A | A | `(1, 0, 0)` |
| A | a | `(0, 1, 0)` |
| a | A | `(0, 1, 0)` |
| a | a | `(0, 0, 1)` |

A/a 与 a/A 是两个不同的配子来源组合，虽然都落到无序基因型 Aa。若推导时只计其中一个，会把 Aa 的概率少算一半。

### P 将配子过程预先合并

令 i、j、k 分别为雌性亲本、雄性亲本、后代的 ZType 索引，u、v 为雌雄配子 GType 索引：

\[
P_{ijk}=\sum_{u=0}^{G-1}\sum_{v=0}^{G-1}M_{0iu}M_{1jv}F_{uvk}.
\]

每一项是“雌性产生 u 的概率 × 雄性产生 v 的概率 × 这对配子产生 k 的概率”。将所有可能配子组合加起来，才得到该亲本组合产生 k 的概率。

对于 Aa × Aa：

| 配子组合 | 贡献 | 归入 |
| --- | --- | --- |
| A × A | 1/2 × 1/2 = 1/4 | AA |
| A × a | 1/2 × 1/2 = 1/4 | Aa |
| a × A | 1/2 × 1/2 = 1/4 | Aa |
| a × a | 1/2 × 1/2 = 1/4 | aa |

所以 `P[1, 1, :]` 是 `(1/4, 1/2, 1/4)`。其他亲本组合也有对应切片：AA × AA 是 `(1, 0, 0)`，AA × aa 是 `(0, 1, 0)`。P 保存这些规则，与当前 AA 是否为零无关。

Python 的 `recompute_offspring_tensor()` 规范化输入为连续 float64 数组，交给 Rust `compute_offspring_tensor_flat()`。Rust 使用行优先偏移 `(i × Z + j) × Z + k` 存放 P，按 i、j、k、u、v 的顺序循环并跳过零项。本例一个 P 元素的值虽很简单，一般模型的累加顺序却影响浮点结果；源码明确保留运算顺序以维持位级一致性。

这里存在明确取舍：P 需要 Z³ 存储，但繁殖时不再为每个亲本组合重新枚举所有配子组合。发布阶段先压缩、后推导 P，正是为了减少这份派生数据的规模。

## 第一步：哪些雄性进入交配对象池

`reproduction()` 从 age-1 读取雄性数量，并乘雄性成体交配率，得到有效雄性向量。令 nⱼᵐ 为雄性类型 j 的数量，rₘ 为雄性成体交配率：

\[
m_j=n_j^m r_m.
\]

本例原始雄性向量是 `(0, 100, 0)`，rₘ=1，因此有效雄性仍是 `(0, 100, 0)`。

`compute_mating_probability()` 再针对每种雌性 i 计算交配对象权重并归一化：

\[
w_{ij}=S_{ij}m_j,\qquad
Q_{ij}=\frac{w_{ij}}{\sum_j w_{ij}}.
\]

S 的行是雌性类型，列是雄性类型。若全部为 1，选择只取决于有效雄性构成；若某些组合更受偏好，其相对权重变大。只有行总和有限且大于 EPS=10⁻¹⁰ 才进行除法，否则构造出的该行 Q 为零。

例如雄性 AA 有 80、aa 有 20。某雌性对二者的 S 分别为 1 和 2，那么权重为 80 和 40，对象概率为 2/3 和 1/3，不是 80% 和 20%。性选择改变的是对象分配，后面还要计算有多少雌性参与交配。

### 雄性不会作为一次性名额被消耗

本例只有 Aa 雄性，Q 的有效对象列为 Aa，概率为 1。把雄性从 100 改为 1，只要有效池仍高于数值阈值，确定性结果仍然把所有参与交配的雌性分配给 Aa 类型。配对数没有被 `min(雌性数, 雄性数)` 限制，雄性计数也不会因配对而扣减。

同理，同一 deme 内对所有雄性类型施加同一个正比例的 rₘ，在正常归一化区间会相消。把 rₘ 从 1 改为 0.5，不意味着后代必然减少一半；rₘ=0 则会使有效雄性池为零。不能将数值阈值附近的极小值也当作这个结论的适用范围。

这是你与 agent 讨论“交配率”时需要特别确认的模型语义。若你的研究需要雄性稀缺导致交配机会下降或限制每雄性交配次数，就需要明确的新机制；仅调整对象权重不自动得到这种限制。

## 第二步：多少雌性交配，配给哪类雄性

令 nᶠᵢ 为雌性类型 i 的成体数量，p 为被限制在 [0,1] 的雌性成体交配率。确定性 `mate_discrete()` 计算：

\[
C_{ij}=n_i^f p Q_{ij}.
\]

C 的单元格表示与雄性类型 j 配对的雌性类型 i 数量。本例 nᶠ=(0,100,0)、p=1，故只有 `C[1,1]=100` 非零。

如果只把雌性交配率改为 0.5，该格就变成 50。这与上一节雄性交配率的作用不对称：雌性率直接控制参与数量，雄性率先参与对象权重。

离散模型的 C 是本步临时缓冲，不是长期精子库。本步结束后，下步会从新的成体数量重新生成它。

## 第三步：配对数变成期望卵数

`fertilize_discrete()` 对每个非零亲本组合读取每雌性产卵数 e、繁殖参与率 b、雌性 fecundity fᶠᵢ 和雄性 fecundity fᵐⱼ。fecundity 在这里表示影响产卵贡献的乘数，不能与交配偏好或生存概率混用。

确定性路径的卵数为：

\[
E_{ij}=C_{ij}\,b\,e\,f_i^f\,f_j^m.
\]

本例为 100 × 1 × 2 × 1 × 1 = 200。若雄性 fecundity 为 0.5，该组合只有 100 个期望卵；这会减少产卵贡献，即使它在上一阶段仍被选择为配偶。

内核的 b 来自成体繁殖率数组。本例离散模型按固定生命周期取 1；年龄结构模型才进一步按年龄处理繁殖参与和 fertility。不要因为同一乘法里有多个率，就把它们当作名称不同但可以互换的参数。

## 第四步：卵数分配到后代类型，并保留遗传损失

对后代类型 k 累加所有亲本组合：

\[
O_k=\sum_i\sum_j E_{ij}P_{ijk}.
\]

本例只有 Aa × Aa 贡献，因此 O 是 200 × `(1/4, 1/2, 1/4)` = `(50, 100, 50)`。

这里的关键是：**一个 P 切片的总和不一定为 1。** 若遗传映射中存在损失，该总和 h 表示这对亲本经映射后保留下来的概率份额。它不包含后面单独施加的 `zygote_viability_fitness`。

考虑一个只用于解释损失的映射变体：将本例融合表 F 的概率全部乘 1/2，则 Aa × Aa 的 P 切片变为 `(1/8, 1/4, 1/8)`，h=1/2。200 个期望卵只贡献 `(25, 50, 25)`，总数为 100。若 agent 为了“使概率合法”把它重新归一化为 `(1/4, 1/2, 1/4)`，就错误地恢复了已经损失的一半数量。

确定性路径直接乘 P；随机路径则先按 h 对卵数作存活抽样，再用 P/h 在保留下来的后代之间分配类型。这两步把“是否保留”与“保留后属于哪一类”区分开。只有后一步才需要条件归一化，存储的 P 不应为此被覆盖。

## 第五步：类型数量分成雌雄

本例没有性染色体，`sex_ratio` 是雌性份额 q=0.5。确定性情况下，各类型先分给雌性 Oₖq，雄性取 Oₖ 减雌性数量的剩余值。于是雌雄各为 `(25, 50, 25)`。

性染色体路径另有判断：固定为雌性或雄性的类型直接归入对应性别；其他类型按雌雄兼容性之比决定雌性份额。兼容性总和不够大时使用 0.5。不能把本例的全局 0.5 不加条件地套到每个物种。

即使全局 q=0.5，最终存活个体也不一定雌雄各半。此后还可能有按性别区分的合子 fitness 和生存率。

## 第六步：合子适应度写入 age-0

分性别之后，`reproduction()` 才按 `zygote_viability_fitness[sex, type]` 施加额外保留。确定性路径乘该值，随机路径使用相应的二项或连续抽样。

本例该值为 1，所以 early 时每个性别的 age-0 仍为 `(25, 50, 25)`。若只令所有雌性的合子 fitness 为 0.5，early 时雌性为 `(12.5, 25, 12.5)`、雄性为 `(25, 50, 25)`，雌性总数 50、雄性总数 100。它改变的是已经分配性别后的存活，不是原本的性别分配概率。

至此繁殖阶段完成。旧成体仍在 age-1；survival 接着进行密度调节与普通 viability，aging 再替换世代。early 观察到的数量包含合子 fitness 的作用，但尚不包含 survival。

### 为什么不能合并所有存活乘数

合子 fitness 在密度调节之前，普通 viability 在密度调节之后。无密度反馈时，某些统一乘数可能碰巧给出同一个末态；这不能证明把它们移动位置在一般模型里成立。

让本例产生 200 个后代，改用 fixed 密度调节、K=100，基础幼体生存率为 1。比较两个场景：

| 场景 | 合子 fitness 后 | fixed 调节后 | 普通 viability 后 |
| --- | --- | --- | --- |
| 合子 fitness=0.5，普通 viability=1 | 100 | 100 | 100 |
| 合子 fitness=1，普通 viability=0.5 | 200 | 100 | 50 |

两种场景都包含一个 0.5，但结果相差一倍，因为密度调节读取的幼体数量不同。如果 agent 提议“把 fitness 统一合并成一个乘数”，必须要求它说明在什么条件下等价。

## 打开随机性后，哪几步发生变化

普通离散整数随机路径保留上述阶段关系，但中间数量由一串有条件的抽样决定：

| 位置 | 抽样含义 |
| --- | --- |
| 雌性参与 | 从取整后的雌性数量中按 p 作二项抽样 |
| 配偶类型 | 根据有效 Q 行作多项分配 |
| 繁殖参与 | 从配对雌性中按 b 保留参与者，接近 1 的分支可直接保留 |
| 产卵 | 以参与者数 × 每配对产卵贡献为均值作 Poisson 抽样 |
| 遗传损失 | 按 h 作二项保留，接近 1 时可跳过抽样 |
| 后代类型 | 按条件概率 P/h 作多项分配 |
| 性别 | 按该类型雌性份额作二项分配，雄性取剩余 |
| 合子 fitness | 雌雄分别作二项保留 |

因此，在本例的整数随机路径中，最终不是强制恰好有 50 个 AA、100 个 Aa、50 个 aa 后代；连总产卵数本身也会波动。确定性算例可以核对公式，但不能证明随机分布、方差或多步平均轨迹正确，尤其存在密度反馈时不能把“随机轨迹的均值”等同于“确定性轨迹”。

本章所读的离散 `fertilize_discrete()` 在随机产卵路径中直接使用 Poisson 或连续对应版本。它**确实包含** `fixed_egg_count` 分支，语义与年龄结构 `fertilize()` 一致：置位时用取整后的期望产卵量替代 Poisson 抽样，两种抽样模式均如此。共享 Blueprint 字段只在实现刻意对齐之处才有相同用法。

`continuous_sampling` 也不是把整数随机结果转成 float。其连续二项函数用 Beta 比例构造，但在 n≤1+EPS 时直接返回 n·p；连续 Poisson 使用 Gamma 抽样；连续多项使用归一化 Gamma 值。它们是另一组数值规则，不能仅凭“结果是小数”认定等同于确定性计算或自动可微。

抽样顺序也是实现行为。多项函数通过连续条件二项抽样分配各类，最后一类取剩余值；空贡献和接近边界的概率可以少消耗随机数。换一个遍历顺序或多作一次随机调用，即使分布目标未变，也可能改变固定 seed 的后续轨迹。

## 需要单独理解的边界

| 情况 | 当前路径中的具体处理 | 不应得出的结论 |
| --- | --- | --- |
| 有效雄性总量或雌性成体总量恰为零 | `reproduction()` 提前返回，保留原状态 | 并非无条件清空 age-0；外部干预放入的幼体可能仍在 |
| 某个 Q 行总权重无效或不大于 EPS | 该行 Q 置零；确定性分配给该行的配对数为零 | 不能仅凭归一化函数推断所有随机下游的退化行为 |
| 某个配对单元为零或负值 | 受精循环跳过它 | 不代表入口允许任意负数量；输入验证仍有独立职责 |
| 遗传切片 h 不大于 EPS | 随机受精分支跳过该组合 | 不能通过强制归一化产生后代 |
| 卵数或某类型贡献不大于 EPS | 相应分支跳过贡献 | 数值阈值附近不能不加条件地使用实数代数等价 |

本章的零亲本验证还包含一个刻意保留 age-0 的情况，以确认提前返回的实际语义。对 Q 全零等特殊随机输入，必须结合采样器和调用链验证；本章不把确定性结果扩展为已经验证的随机保证。

## 年龄结构模型多出了什么

年龄结构的 `sample_mating()` 更新按 `(female age, female type, male type)` 组织的精子存储。一个格子表示携带该雄性类型精子的已交配雌性数量，不是精子细胞个数，也不是独立存活的雄性数量。

`fertilize()` 遍历可繁殖年龄与存储的亲本组合。每配对产卵贡献还乘该年龄的 fertility，并使用该年龄的繁殖参与率。雌性可以凭已存储精子繁殖；“本步没有新配对”不自动等于“本步没有后代”。随后 survival 和 aging 还必须让雌性数量、精子存储和年龄对应关系保持一致。

因此，用一个 `(Z,Z)` 临时配对表替代长期存储，会改变模型历史依赖。融合 Wright–Fisher 则又是独立更新路径，不执行这里完整的分阶段组合。对这两类模型的修改，不能只凭本章离散案例验收。

## 如何验收 agent 对繁殖的修改

先要求 agent 说明改的是哪一个量：对象权重 Q、配对数量 C、卵数 E、遗传映射 P、性别份额，还是某个阶段的存活。只说“调整繁殖率”不足以确定实现位置。

随后要求证据能区分容易混淆的方案：

| 验收问题 | 本章对应的可区分场景 |
| --- | --- |
| 是否漏计一个配子来源组合？ | Aa × Aa 的中间两条路径都必须贡献 Aa |
| 是否错误约束或消耗雄性？ | 单雄性类型下比较 1 与 100 个雄性的确定性结果 |
| 是否混淆两种交配率？ | 分别只降低雌性率、只降低正的统一雄性率 |
| 是否抹去了遗传损失？ | P 切片总和为 1/2 时应保留相应损失 |
| 是否错误移动 fitness？ | fixed K=100 的前后两个 0.5 场景 |
| 是否只验证了最终总量？ | 核对类型、性别、early/late 阶段及最终年龄槽 |
| 是否声称随机等价？ | 另行说明检验的是分布、均值、方差还是 seed 重放，以及证据范围 |

这是行为验收路线，不要求你亲自阅读 Rust 循环。agent 的任务是提供相应输入、预期依据和实际结果，而不是仅汇报“测试通过”。
