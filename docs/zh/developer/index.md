# 开发者指南

这套指南面向需要理解、维护或扩展 NATAL Core 的开发者。阅读前应能按照[快速开始](../1_quickstart.md)构建并运行一个种群；这里从这一操作继续向下，追踪它如何变成数组、引擎会话和数值计算。

指南解释当前实现中的协作关系与约束。完整参数列表仍见 [API 参考](../api/index.md)。文中出现的私有函数是源码阅读入口，不构成公开 API 的稳定性承诺。

## 从两个样章开始

先读[一个模型从声明到结果的完整旅程](model_journey.md)，跟随同一个模型理解类型目录、概率表、运行会话和输出；再读[一次繁殖如何计算](reproduction.md)，逐项推导配对、产卵、遗传分配及各阶段的数量变化。

两个样章与后续章节都以“不先读源码也能理解过程、评估 agent 方案”为目标，包含完整数值案例和可区分不同实现的验收问题。**全文专题章节已按同一深度补齐**：每个页面把算法、边界与验收方式写进正文，而不是只给模块清单。

## 如何配合源码阅读

先沿正文中的案例理解输入、中间状态和结果；源码与测试链接供你或 agent 在需要时核实实现，不要求先读完源码才能理解正文。源码和测试链接指向仓库 `main`；研究旧版本时应切换到同一提交的文档、代码和测试，避免混用版本。

每章的“验证入口”指出已有测试保护的行为，不表示这些测试在每次文档阅读或构建时自动执行。函数名、数组轴和边界条件用于定位事实；解释性计算不是可以直接运行的 Python 示例。

既有用户文档的“内部实现”和附录仍保留原入口。这套指南提供连续的开发者阅读路线，历史设计页面只提供演变背景。浏览器界面（仓库根目录 `ui/` 与 `src/natal/frontend/webui/`）不在本指南范围内，见[开发实践](development.md)末尾的说明。
