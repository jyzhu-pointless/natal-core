Numerical Aggregation Toolkit for Analysis of Lifecycles

种群遗传，聚合计算。

基于数值聚合的前向种群遗传模拟引擎。支持可配置的生命周期，用于研究基因驱动及其他种群遗传过程。

pip install natal-core
开始建模 ↗v0.3.0

数值聚合

按年龄、性别、基因型与自定义标签组织种群，以各类群的数量进行聚合计算。

可配置的遗传结构

定义染色体、位点及其等位基因，配置模型的遗传结构。

点突变

Homing

Toxin–antidote · TARE

可配置的遗传规则

通过预设配置遗传机制，包括点突变、homing 和 toxin-antidote。

可配置的生命周期

配置繁殖、生存与增龄阶段，通过 hooks 在阶段前后加入释放等干预。

高性能计算引擎

使用 Python 配置模型，由 Rust 后端执行种群状态更新。

空间模型

在相互连接的局部种群间模拟迁移，观察基因驱动扩散与种群数量变化。

对研究者与 AI agent 友好

链式 API、类型标注和示例，便于研究者与 AI agent 阅读、编写和修改模型配置。
